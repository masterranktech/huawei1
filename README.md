# 🌐 Huawei Corporate Portal (Frontend Recreation)

A responsive corporate web portal recreation based on Huawei's enterprise web layout. Built with modern HTML5, clean CSS Grid/Flexbox architecture, and vanilla JavaScript.

## ✨ Features
- **Responsive Grid:** Dynamic asymmetrical cards using modern CSS Grid that reorganize cleanly between desktop, tablet, and mobile viewports.
- **Micro-Interactions & Hover Polish:** Subtle depth zooms, brightness shifts, and animated call-to-action triggers on card focus.
- **Mobile Drawer Navigation:** Lightweight vanilla JS menu toggle for touch devices without external framework overhead.
- **Enterprise Sectioning:** Dual showcase banners, press release feeds, global corporate footers, and accessible modal triggers.

## 🛠️ Tech Stack
- **HTML5:** Semantic architecture (`<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`).
- **CSS3:** Custom Properties (CSS variables), CSS Grid, Flexbox, media queries.
- **JavaScript (ES6):** Accessible DOM toggle handling for responsive mobile menus.
